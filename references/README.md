## 등록 규칙

- 사이트별 `site-slug.md` 파일을 생성합니다.
- 원본 URL, 분석 날짜, 검증 상태를 기록합니다.
- 실제 관찰과 추론을 구분하고, 확인되지 않은 항목은 미확인으로 표기합니다.
- 새로운 레퍼런스가 등록되면 위 인덱스를 갱신합니다.
